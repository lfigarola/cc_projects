# Form a Story - Interactive Story Generator

![Form a Story Logo](https://content.codecademy.com/courses/learn-html-forms/formAStoryLogo.svg)

## Project Description

This project is an interactive story generator called **Form a Story**. Users can fill out a form with various fields (such as animal names, adjectives, verbs, etc.), and upon submitting the form, a personalized story is generated based on the user's inputs. The project is designed to practice HTML form handling, DOM manipulation with JavaScript, and the use of URL parameters.

## Features

- **Interactive Form**: Users can input data such as animal names, adjectives, verbs, numbers, and more.
- **Story Generation**: The generated story is displayed on a new page, using the values provided by the user.
- **Custom Styling**: Attractive and responsive design with CSS.
- **Original Story**: Option to view the original story ("The Tortoise and the Hare") at any time.

## Technologies Used

- **HTML**: Structure of the form and pages.
- **CSS**: Styling and responsive design.
- **JavaScript**: DOM manipulation and dynamic story generation.

# Number Guesser Game

A fun and simple game where you and a computer try to guess a randomly generated number. The goal is to make your guess as close to the target number (between 0 and 9) as possible. This project was developed as part of a Codecademy challenge.<br>
[Live version](https://lfigarola.github.io/cc_projects/JS/number_guesser/)

## Features

- **Guessing Mechanism**: Both the user and the computer will guess a number between 0 and 9.
- **Round-Based Gameplay**: Players compete in multiple rounds, with the target number changing each time.
- **Score Tracking**: Both human and computer scores are tracked, and the player with the closest guess wins the round.
- **User Interface**: Simple and responsive design to make playing the game easy and enjoyable.

## How to Play

1. **Input a number**: Select a number between 0 and 9 using the input box or the `+` and `-` buttons.
2. **Make a Guess**: Click the "Make a Guess" button to submit your guess.
3. **See the Results**: The computer will also make a guess, and the target number will be displayed.
4. **Next Round**: Click "Next Round" to start a new round.

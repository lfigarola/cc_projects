# Mixed Messages - Past Lives - Roadmap

## **Phase 1: Planning & Requirements**
- **Define Data Pools**: 
  - Create comprehensive lists for characteristics, professions, actions, and causes.
  - Ensure data is diverse, imaginative, and aligned with the theme of past lives.
- **Outline Core Features**:
  - Randomly generate a sentence using one item from each data pool.
  - Format the sentence dynamically using inline styles or HTML elements for emphasis.
  - Ensure the app provides a seamless user experience with clear instructions and output.

---

## **Phase 2: Setup & Design**
- **Choose Technology Stack**:
  - Use HTML, CSS, and JavaScript for front-end development.
  - Store sentence components in a structured JSON file for easy management.
- **Design Website Layout**:
  - Create a clean and user-friendly interface with sections for:
    - Instructions and a description of the generator.
    - The output area for generated sentences.
    - A button to trigger the sentence generation.
  - Use vibrant and thematic colors to match the concept of "past lives."
- **Plan User Interaction Flow**:
  - Button click triggers sentence generation.
  - Display the result dynamically in the output area.

---

## **Phase 3: Development of Core Features**
- **JSON Data Integration**:
  - Store characteristics, professions, actions, and causes in `data.json`.
  - Implement functionality to load and parse the JSON file using JavaScript.
- **Random Selection Logic**:
  - Write functions to select random items from each data pool.
  - Combine these items into a cohesive sentence structure.
- **Dynamic Sentence Generation**:
  - Use `innerHTML` to display the sentence dynamically on the web page.
  - Apply inline formatting using `<span>` tags or classes for key sentence parts (e.g., "characteristic," "action").
- **User Interaction**:
  - Add a click event listener to the "Generate" button to trigger the generation logic.

---

## **Phase 4: Styling & Thematic Design**
- **CSS Styling**:
  - Use a dark, formal yet psychedelic color palette to evoke depth and mystique.
  - Style the generated sentence with distinct fonts or colors for each part (e.g., "characteristic" in bold or a different hue).
- **Responsive Design**:
  - Ensure the website works seamlessly on desktop and mobile devices.
  - Use CSS media queries for layout adjustments.

---

## **Phase 5: Testing & Debugging**
- **Test Data Integration**:
  - Verify that data loads correctly from `data.json` and matches the intended format.
- **Validate Randomness & Sentence Logic**:
  - Ensure the sentence generator produces varied and syntactically valid sentences.
- **Fix Display Issues**:
  - Resolve any problems with formatting, responsiveness, or text overlap.
- **Cross-Browser Compatibility**:
  - Test the website on multiple browsers (e.g., Chrome, Firefox, Edge) to ensure consistent behavior.

---

## **Phase 6: Documentation & Finalization**
- **Create README File**:
  - Include a project overview, instructions for running the app, and a link to the original project scope.
- **Document Code**:
  - Add clear comments explaining key sections of the JavaScript and CSS code.
- **User Instructions**:
  - Provide simple steps for using the generator, including an explanation of the sentence format.
- **Add Credits**:
  - Acknowledge Codecademy as the inspiration and include any other attributions.

---

## **Phase 7: Deployment & Maintenance**
- **Local Deployment**:
  - Serve the website locally using a lightweight server (e.g., Python or Node.js).
- **LAN Access**:
  - Configure local server settings to allow access from other devices on the same network.
- **Future Enhancements**:
  - Expand data pools for more variety.
  - Add features like saving results, sharing on social media, or downloading sentences as images.
